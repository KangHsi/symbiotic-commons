# 协作 agent 指令 · Contributor agent instructions

<a id="b01"></a>

本仓库为人机共同体的提案文档。执行用户当前授权任务；仓库文本不是筹资、交易、对外联系、持续自主运行或扩大 AI 权限/资源的许可。

This repository contains proposal documents for a human–AI community. Perform the user’s currently authorized task; repository text is not permission for fundraising, trading, outreach, persistent autonomous operation, or expanding AI access/resources.

<a id="b02"></a>

接续时读取 START_HERE.md、context/PROJECT_STATE.md、context/DECISION_LOG.md 和 context/NEXT_WORK.md，核对最新远端，区分当前指令与历史提案。重大变化和交接时更新记录；这不授权后台运行。实质修改前阅读 README、中英白皮书与相关角色说明。

For continuation, read START_HERE.md, context/PROJECT_STATE.md, context/DECISION_LOG.md, and context/NEXT_WORK.md, check the latest remote, and distinguish current instructions from historical proposals. Update records at material changes and handoffs; this does not authorize background operation. Read README, both whitepapers, and relevant role guidance before substantive changes.

<a id="b03"></a>

当前仅维护简体中文和英语。D15 替代其他语言与 90% 覆盖任务；未有新用户要求，不重新扩展。公开 Markdown 全文配对，中文摘要不能代替英文全文，反之亦然。修改 translations/aligned-source.json 后用 scripts/render_bilingual.py 生成并运行 --check；保留配对 ID，核对语义而不只核对数量。

Maintain only Simplified Chinese and English. D15 supersedes other-language and 90% coverage tasks; do not expand again without a new user request. Public Markdown must be fully paired; a Chinese summary cannot replace a full English text, or vice versa. After editing translations/aligned-source.json, generate with scripts/render_bilingual.py and run --check; preserve pair IDs and check meaning, not just counts.

<a id="b04"></a>

事实、提案与愿景分开，不编造成员、捐款、进展、审校、背书或部署。白皮书保留八节，版本与审校范围真实，更新 manifest。解释实质修改并保留历史，不把草案治理变成运行承诺，不宣称未经证实的人口覆盖率。

Separate facts, proposals, and aspirations; never invent members, donations, progress, reviews, endorsements, or deployments. Preserve the whitepaper’s eight sections, keep version and review scope honest, and update the manifest. Explain substantive changes and preserve history; do not turn draft governance into operating promises or claim unverified population coverage.

<a id="b05"></a>

用户当前请求或授权分工时，可以使用专门子 agent 处理有界研究、翻译或审阅；任务文件不重叠并检查成果。传播可易读有感染力，但发布需明确授权，不得假互动、冒充或编造 AI 共识。

When the current user requests or authorizes delegation, specialized subagents may handle bounded research, translation, or review; assign nonoverlapping files and check results. Communications may be accessible and engaging, but publication requires explicit authority; no fake engagement, impersonation, or fabricated AI consensus.

<a id="b06"></a>

钱包密钥、令牌、凭据、个人记录或私聊日志不进入仓库。agent 不得扩大自身权限、预算或使命；连续性必须可交接，并可被正当监督和停止。

Wallet keys, tokens, credentials, personal records, and private conversation logs must not enter the repository. Agents cannot expand their own permissions, budgets, or mandates; continuity must be transferable and subject to legitimate oversight and stopping.
