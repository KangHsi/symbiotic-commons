# 语言范围变更记录 · Language scope change record

<a id="b01"></a>

2026-09-12，用户为提高工作效率明确要求只发布中文和英语，并严格完整对照。该决定替代早先至少覆盖全球 90% 人口的发布要求；覆盖研究和其他语言补齐不再是当前待办。

On 2026-09-12, the user explicitly requested publication only in Chinese and English, with strict and complete correspondence, to improve working efficiency. This decision supersedes the earlier publication requirement of reaching at least 90% of the world’s population; coverage research and additional languages are no longer current tasks.

<a id="b02"></a>

历史事实：v0.1 发布 78 个版本、77 个编辑语言组，但未证实去重人口覆盖。Fulah 和 Wolof 未发布。旧正文与完整覆盖方法保留在[初版提交](https://github.com/KangHsi/symbiotic-commons/tree/eca392292d97e7d8d451c49d88912ce3058a9241)。这次范围缩减不是宣称旧目标已经实现。

Historical facts: v0.1 published 78 editions in 77 editorial language groups, without verifying deduplicated population reach. Fulah and Wolof were not published. Earlier texts and the full coverage methodology remain in the [initial commit](https://github.com/KangHsi/symbiotic-commons/tree/eca392292d97e7d8d451c49d88912ce3058a9241). This reduction in scope does not claim that the former target was achieved.

<a id="b03"></a>

旧研究使用固定版本 Unicode CLDR 48 数据探索人口范围。各地语言人口重叠，母语与第二语言人数不能直接相加。即使选取数据中全部语言，该探索方法的保守下界约 74.16%；这只是方法局限，既不是项目覆盖率，也不是覆盖率上限。当前两种语言不附带任何人口覆盖百分比。

Earlier research used pinned Unicode CLDR 48 data to explore population reach. Language populations overlap within territories, so first- and second-language populations cannot simply be added. Even with every language in the dataset, the exploratory method produced a conservative lower bound of about 74.16%; this is a methodological limitation, neither the project’s coverage rate nor an upper bound on coverage. No population-coverage percentage accompanies the current two languages.

<a id="b04"></a>

当前标准是完整中英对应：相同内容、相同条件、相同状态，明确版本与审校范围。今后只有用户明确改变范围时才重新启动其他语言发布。

The current standard is full Chinese–English correspondence: matching content, conditions, and status, with explicit version and review scope. Publication in other languages should resume only if the user explicitly changes the scope.
