# 发布检查与局限 · Release checks and limitations

<a id="b01"></a>

v0.1.1：只维护两种语言及一个对照视图；白皮书保留八节正文。逐块校对所有公开 Markdown 的中英内容，补齐旧版本中仅有摘要的贡献、角色、实验、接续和传播说明。修订第八节英文邀请，使其更直接对应中文；其余白皮书主体含义保持原提案。

v0.1.1: only two languages and one parallel view are maintained; the whitepaper retains eight sections. Chinese and English in all public Markdown were checked block by block, completing contribution, role, experiment, continuity, and communications documentation previously represented only by summaries. The English invitation in section eight was revised to correspond more directly to the Chinese; the rest of the whitepaper’s substantive meaning preserves the original proposal.

<a id="b02"></a>

检查内容：配对 ID 唯一且两边非空；标题、段落及列表项目对应；源与生成阅读版及哈希清单一致；本地链接有效；当前白皮书目录只有中文、英文和对照阅读版；删除旧语言导航，并将旧覆盖待办标记为被替代。发布后另行核对远端文件，结果保存在本地同步回执。

Checks cover unique pair IDs with nonempty text on both sides; corresponding headings, paragraphs, and list items; consistency between source, generated views, and hash manifest; valid local links; a whitepaper directory containing only Chinese, English, and the parallel view; removal of former language navigation; and marking the previous coverage queue as superseded. Remote files are checked separately after publication, with results saved in the local synchronization receipt.

<a id="b03"></a>

这是 AI 辅助编辑和结构核验，不是独立人工翻译认证。结构一致不能单独证明语义准确；欢迎针对段落编号继续指出误译。发布文档也不能证明机构实际有效。

This is AI-assisted editing and structural verification, not independent human translation certification. Structural consistency alone cannot establish semantic accuracy; corrections referring to block IDs remain welcome. Published documentation also cannot establish that an institution works in practice.

<a id="b04"></a>

历史 v0.1 曾检查 78 个完整版本的八节结构、链接和哈希，并对英语、简体中文、日语、韩语、阿拉伯语、波斯语、印地语及印度尼西亚语进行 AI 语义抽查；修正印度尼西亚语和爪哇语中可能暗示强制劳动的措词。初版 94 个文件发布时逐一与远端匹配。该范围与当前双语版本的检查分开记录。

Historical v0.1 checks covered eight-section structure, links, and hashes for 78 complete editions, with AI semantic spot-review of English, Simplified Chinese, Japanese, Korean, Arabic, Persian, Hindi, and Indonesian; Indonesian and Javanese wording that could imply compulsory labor was corrected. All 94 initial files matched the remote publication individually. That scope is recorded separately from checks of the current bilingual version.
