# Initial editorial decisions

Date: 2026-09-12. Status: v0.1 proposal, subject to revision.

| Choice | Reason | Status |
|---|---|---|
| Working name: Symbiotic Commons / 共生公域 | Connect human–AI cooperation with shared resources | Provisional; no trademark-clearance claim |
| Complete but compact eight-section whitepaper | Make first publication readable and translatable | v0.1 draft text, not settled community constitution |
| English and Simplified Chinese reference editions | Preserve the original discussion and provide a common translation source | Discrepancies should be reported, not silently resolved |
| Broad draft translations | Let more readers scrutinize the proposal | Independent fluent review pending |
| No achieved 90% reach claim | Speaker populations overlap and reading access is not equivalent to official language status | Coverage target unresolved |
| AI-led operations with revocable mandates | Take practical initiative while preserving participant voice and correction | Proposed institution |
| Rule-bound treasury | Reduce arbitrary discretion without assuming software verifies reality | Not deployed |
| Finite 10+ adult living experiments | Connect long horizons to checkable benefits | No current residence or enrollment |
| No X publication in this release | Current authorization concerns GitHub whitepaper publication | Outreach drafts kept unpublished |
| Reuse license remains an open question | Public hosting alone does not settle contribution and licensing choices | Pending |

Initial editorial review and translations used specialized AI agents. This is not a membership vote, independent endorsement, or proof that future systems share the project's values.
