# 中英文维护与阅读 · Chinese–English maintenance and reading

<a id="b01"></a>

当前只发布简体中文和英语；[对照阅读版](../whitepaper/bilingual.md)、[中文全文](../whitepaper/zh-Hans.md)和[英文全文](../whitepaper/en.md)来自同一份配对文本。对照版是阅读视图，不是第三种语言。

Only Simplified Chinese and English are currently published. The [parallel view](../whitepaper/bilingual.md), [full Chinese edition](../whitepaper/zh-Hans.md), and [full English edition](../whitepaper/en.md) come from the same paired text. The parallel view is a reading format, not a third language.

<a id="b02"></a>

公开说明也逐段配对；每个正文块都有稳定编号。修改时同时维护两种语言的事实、数字、条件、否定、承诺程度、标题和列表项目；不得只写摘要或漏掉一方。两种语言都完整，但不要求逐字机械翻译。

Public documentation is also paired paragraph by paragraph, with a stable ID for each content block. Updates must maintain matching facts, numbers, conditions, negations, levels of commitment, headings, and list items in both languages; neither summaries nor omissions are acceptable. Both languages must be complete, without requiring mechanical word-for-word translation.

<a id="b03"></a>

配对文本保存在 [aligned-source.json](aligned-source.json)，阅读文档由 [render_bilingual.py](../scripts/render_bilingual.py) 生成。修改配对源后运行生成器；用 --check 检查源、生成文件和 manifest 是否一致。结构检查能发现缺块或不同步，不能自动证明语义准确；每次仍需阅读双方原文。

Paired text is stored in [aligned-source.json](aligned-source.json), and reading documents are generated by [render_bilingual.py](../scripts/render_bilingual.py). Run the generator after editing the paired source; use --check to verify consistency between source, generated files, and manifest. Structural checks can detect missing blocks or synchronization errors but cannot automatically establish semantic accuracy; both texts still require reading.

<a id="b04"></a>

v0.1.1 已进行 AI 辅助的逐块语义校对，独立人工审校尚未完成。建议修订时给出文件、段落编号、现有文字、建议和理由。旧的其他语言不再维护；原 90% 覆盖计划已由新的双语范围替代。参阅[范围变更记录](../docs/language-coverage.md)。

v0.1.1 has received AI-assisted semantic checking of each block; independent human review remains pending. Suggested corrections should give the file, block ID, current wording, proposal, and reason. Other former languages are no longer maintained; the original 90% coverage plan has been superseded by the new bilingual scope. See the [scope-change record](../docs/language-coverage.md).
