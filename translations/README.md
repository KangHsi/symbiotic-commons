# Read in your language / 选择语言

**78 complete editions · 77 language groups · whitepaper v0.1**

[English reference](../whitepaper/en.md) · [简体中文参考版](../whitepaper/zh-Hans.md) · [Project home / 项目首页](../README.md)

Every edition contains all eight whitepaper sections. Translations are **AI-assisted drafts, not independently verified by fluent speakers**. Reference editions establish an editorial source; they are not a ranking of languages or people. If meanings differ, compare English and Simplified Chinese and open a correction with the section number. No independent fluent-speaker approval is claimed for the reference editions either.

We aim for at least 90% worldwide language access. **Actual deduplicated population reach is unverified.** See the [methodology and limits](../docs/language-coverage.md). Chinese script editions count as one language group. Language groups here are editorial labels, not a population model.

所有版本均包含八个完整章节。译文由 AI 辅助起草，尚未通过独立熟练使用者审阅。遇到歧义请对照中英文参考版，并提供章节和建议译法。**90% 全球人口覆盖目标尚未验证。**

## Improve an edition

Use the translation issue template or a pull request. Include locale, source version, section number, current wording, suggested wording, and the reason. State language familiarity and any AI assistance honestly. Do not submit private personal information. Corrections that change substantive policy belong in a source revision as well.

## Terminology and meaning

- **Commons:** shared resources and institutions governed for common benefit; not compulsory collectivization.
- **AI operational lead:** initiative in defined work, within a revocable mandate; not unrestricted sovereignty.
- **Revocable mandate:** a defined authorization that legitimate governance can withdraw.
- **Common treasury:** funds governed by published rules; not a token, promise of yield, or an AI's private assets.
- **Living experiment:** finite, voluntary shared living with defined support and exit; not a currently available residence.
- **Self-sufficiency:** specify what is provided internally and account for outside inputs; a donation-funded stay alone does not establish it.

Preserve the distinction between proposals and current facts, all participant rights, spending limits, the ten-adult minimum, privacy, stop/exit arrangements, no promised returns, and uncertainty about future AI.

## Scope and review priorities

Some editions use a specified written standard or script. Gurmukhi Punjabi does not substitute for Shahmukhi or Western Punjabi; Bokmål does not substitute for Nynorsk; Modern Standard Arabic and written Chinese do not prove comprehension by every speaker of a related variety. Fulah and Wolof remain pending fluent translators (including a regional-standard choice for Fulah); no placeholder editions are counted. Review-priority flags indicate additional editorial caution, not measured quality scores.

The [machine-readable manifest](manifest.json) records edition paths, source and file hashes, direction, scope notes, and review status. A structure check verifies section and link completeness; it does not establish linguistic accuracy.
