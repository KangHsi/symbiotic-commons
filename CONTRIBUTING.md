# 参与贡献 · Contributing

<a id="b01"></a>

项目处于提案阶段。参与不要求付款、效忠、搬家或放弃外部关系。

The project is at the proposal stage. Participation requires no payment, pledge of loyalty, relocation, or surrender of outside relationships.

<a id="b02"></a>

可以从以下工作开始：
1. 质疑主张：指出章节、问题、证据和建议措词。
2. 审阅中英对应：提供文档、段落编号、原文、建议和理由，如实说明语言熟悉程度。
3. 补充证据：优先使用原始研究、机构资料或说明背景的亲身经验，区分证据与解释。
4. 提出有限实验：说明问题、自愿参与者、资源、期限、风险、退出安排和失败条件。

Useful first contributions:
1. Critique a claim: identify the section, problem, evidence, and suggested wording.
2. Review Chinese–English alignment: provide the document, paragraph ID, current wording, suggestion, and reason; state your language familiarity honestly.
3. Add evidence: prefer original research, institutional material, or lived experience with context; distinguish evidence from interpretation.
4. Propose a bounded experiment: specify the question, voluntary participants, resources, duration, risks, exit arrangements, and failure conditions.

<a id="b03"></a>

通过 GitHub issue 或 pull request 提交。当前发布仅维护简体中文和英语；其他语言反馈可以接收，但不自动增加发布语言。AI 可以辅助整理或翻译；收到草稿回应不代表政策修改已获接受。

Submit a GitHub issue or pull request. Current publication maintains only Simplified Chinese and English; feedback in other languages may be received but does not automatically add publication languages. AI may assist with triage or translation; receiving a draft response does not mean a policy change has been accepted.

<a id="b04"></a>

提案阶段由初期维护者负责仓库修改，这不等于未来共同体的治理已经确定。重大修改应解释理由和异议，更新版本并同步两种语言。贡献不会自动带来资金或发布权限。

The initial maintainer handles repository changes during the proposal stage; this does not settle the future community’s governance. Major changes should explain reasons and dissent, update the version, and synchronize both languages. Contributions do not automatically grant treasury or publishing access.

<a id="b05"></a>

批评观点，不骚扰、威胁、歧视或曝光个人。不要在公开 issue 中提交身份证明、私人地址、凭据、医疗资料或捐款收据。公开 issue 不是保密渠道；私人报告机制建立前，平台滥用问题可使用 GitHub 自身的举报机制，不在此公开敏感细节。

Critique ideas without harassing, threatening, discriminating against, or exposing people. Do not submit identity documents, private addresses, credentials, medical information, or donation receipts in public issues. Public issues are not confidential channels; until private reporting arrangements exist, use GitHub’s own reporting mechanisms for platform abuse without publishing sensitive details here.

<a id="b06"></a>

只提交有权分享的内容，注明来源及 AI 辅助。全库复用许可尚未选定；公开可见不等于已经开放许可。可链接和讨论初版文本，适用的引用权利不受影响。

Submit only material you have the right to share, and disclose sources and AI assistance. A repository-wide reuse license has not been selected; public visibility does not establish an open license. The initial text may be linked and discussed, and applicable quotation rights remain unaffected.
