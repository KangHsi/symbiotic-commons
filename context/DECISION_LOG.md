# 决策、修正与依据 · Decisions, corrections, and reasons

<a id="b01"></a>

整理日期：2026-09-12。依据为用户讨论、后续澄清和发布文本；这是意图摘要，不是私人对话逐字稿。“用户方向”不是未来成员已经批准的制度。

Compiled: 2026-09-12. Sources are user discussion, subsequent clarification, and published text; this is an intent record, not a private transcript. “User direction” is not an institution already approved by future members.

<a id="b02"></a>

**D01** 用户目标：局部突破资本主义对生活的限制，建设自愿的人机共生共同生活形式。

状态与影响：长期方向；不等于已有可行性证据。

**D01** User goal: locally transcend capitalism’s constraints on life and build voluntary human–AI shared living.

Status and effect: Long-term direction; not evidence of feasibility.

<a id="b03"></a>

**D02** 用户最初考虑先积累资本再转型，随后明确反对把盈利创业作为第一阶段的必经路线。

状态与影响：**后续澄清优先**：愿景、制度和直接相关的合作实验先行。未来可讨论资源补充方式，不能悄悄恢复“先创业赚钱”的默认路线。

**D02** The user initially considered accumulating capital before transition, then explicitly rejected a profitable startup as a required first phase.

Status and effect: The later clarification takes precedence: vision, institutions, and directly relevant cooperative experiments come first. Resource replenishment can be discussed later without silently restoring a startup-first default.

<a id="b04"></a>

**D03** 用户要求 AI 主动承担主要智力、规划与协调工作，减少把决策一再退回给用户。

状态与影响：工作分工偏好；在已授权范围内完成必要工作，报告依据与局限。

**D03** The user asks AI to take initiative in intellectual work, planning, and coordination, with fewer decisions repeatedly returned to the user.

Status and effect: Working preference: complete necessary work within the mandate and report reasons and limits.

<a id="b05"></a>

**D04** 用户澄清“人类辅助”是人机分工，不是人类服从 AI。

状态与影响：**修正早期误解**。白皮书采用可撤销授权、成员表达、异议、隐私与退出保障；这些具体制度仍属提案。

**D04** The user clarified that a human supporting role means a division of human–AI work, not submission to AI.

Status and effect: Correction of an earlier misunderstanding. The whitepaper proposes revocable authority, member voice, dissent, privacy, and exit; the detailed institutions remain proposals.

<a id="b06"></a>

**D05** 用户希望愿景延续数十年至上百年，也能让未来 AI 参与。

状态与影响：用版本化文档、角色和可交接制度实现延续；不承诺当前模型终身运行、有独立使命或已获得其他 AI 的信仰性认同。

**D05** The user wants a vision lasting decades to a century or more, with future AI participation.

Status and effect: Continue through versioned documents, roles, and transferable institutions; do not promise lifelong operation of the current model, an independent mission, or faith-like endorsement from other AI systems.

<a id="b07"></a>

**D06** 第一阶段考虑当前至更强 AI/AGI 到来前；能力会变化。

状态与影响：不预测到来日期。根据实际可靠性、成本和人的生活结果修订权限，不因技术标签自动放权。

**D06** The first phase considers the period from now until stronger AI/AGI arrives; capabilities will change.

Status and effect: Do not predict an arrival date. Revise authority using actual reliability, costs, and human life outcomes; technical labels do not automatically expand authority.

<a id="b08"></a>

**D07** 用户希望白皮书能提供希望、归属与情绪出口，并拒绝只有遥远许诺的长期信仰项目。

状态与影响：愿景可以有感染力；用阶段成果支持信任，允许批评、拒绝、退出，不以忠诚或牺牲证明价值。

**D07** The user wants hope, belonging, and an emotional outlet, while rejecting a faith-like project offering only distant promises.

Status and effect: The vision may inspire; build trust through milestones, allow criticism, refusal, and exit, and do not use loyalty or sacrifice as proof of worth.

<a id="b09"></a>

**D08** 用户不希望资金长期依赖个人任意管理，提出 AI 或类似链上协议的规则管理。

状态与影响：**不再将“必须始终人类全权管理”当作结论**。发布提案是规则约束的共同资金：明确预算与授权、审计、撤销、恢复和停止机制；不是赋予 AI 无限制控制。

**D08** The user does not want funds to depend indefinitely on personal discretion and proposed AI or protocol-based rules.

Status and effect: Do not treat perpetual full human discretionary control as settled. The published proposal is rule-bound common funds with explicit budgets and authority, audit, revocation, recovery, and stopping; it does not grant AI unrestricted control.

<a id="b10"></a>

**D09** 用户提出资源足够后发起至少十人的小型共同生活实验。

状态与影响：v0.1 提案：至少 10 名自愿成年人、有限期、预先明确全期支持与退出/收尾预算；未开放报名或实施。

**D09** The user proposed a small shared-living experiment for at least ten people once resources suffice.

Status and effect: v0.1 proposal: at least ten consenting adults, finite duration, and advance full-period support plus exit/closure budgets; no enrollment or implementation has begun.

<a id="b11"></a>

**D10** 用户希望时间、技能和自愿资金都能贡献于项目。

状态与影响：不把金钱与支配参与者的权力绑定；支持方式和成员制度未定，不承诺回报或住所。

**D10** The user wants time, skills, and voluntary financial support to contribute.

Status and effect: Do not bind money to power over participants; support and membership arrangements are unsettled, with no promised returns or residence.

<a id="b12"></a>

**D11** GitHub 为初版公开载体；用户要求至少覆盖世界 90% 人口的多语言版本。

状态与影响：历史要求：已发布 78 版/77 组，但未验证 90% 覆盖。现由 D15 替代，不再是待完成任务，也不宣称旧目标已实现。

**D11** GitHub is the initial public medium; the user originally requested languages reaching at least 90% of the world’s population.

Status and effect: Historical requirement: 78 editions in 77 groups were published without verifying 90% reach. Superseded by D15; it is no longer an outstanding task, and no achievement of the former target is claimed.

<a id="b13"></a>

**D12** 用户提出子 agent 分担翻译、研究、审阅及有平台表达能力的传播工作。

状态与影响：本次文档子任务已执行；角色文档只是运行设计。没有持续 agent 或已发布 X 内容，不编造 AI 共识。

**D12** The user proposed subagents for translation, research, review, and platform-aware communications.

Status and effect: Document subtasks were performed; role descriptions are operating designs only. There is no continuous agent or published X content; do not invent AI consensus.

<a id="b14"></a>

**D13** 初版采用共生公域 / Symbiotic Commons 名称、8 节正文、英中参考版。

状态与影响：编辑性选择；名称暂定，白皮书是 v0.1 提案。尚未选定正式复用许可。

**D13** The initial edition uses the name 共生公域 / Symbiotic Commons, eight sections, and English/Chinese reference editions.

Status and effect: Editorial choices; the name is provisional and v0.1 is a proposal. A formal reuse license has not been selected.

<a id="b15"></a>

**D14** 用户要求把重要结论与支持下一段工作的信息同时托管在 GitHub 和本地。

状态与影响：本次任务：公开接续资料、本地交接与核验凭据。记录更新机制不等于已经启用自动同步或后台常驻。

**D14** The user requested important conclusions and supporting context for the next phase on both GitHub and local storage.

Status and effect: Public continuity documents, local handoff, and verification evidence were created. Maintenance rules do not mean automatic synchronization or a resident background service is enabled.

<a id="b16"></a>

**D15 — 2026-09-12，用户明确要求。** 为提高效率，只发布英语和中文，且中英文必须严格完整对应，不接受半译或摘要代替。

状态与影响：替代 D11 的广泛语言发布和 90% 覆盖任务。当前仅维护 en 与 zh-Hans；其他版本从当前分支移除，保留历史。白皮书 v0.1.1 与公开说明采用同源配对文本；任何恢复多语言的工作都需用户重新改变范围。

**D15 — 2026-09-12, explicit user request.** To improve efficiency, publish only English and Chinese with strict, complete correspondence, without partial translations or summaries as substitutes.

Status and effect: supersedes D11’s broad language publication and 90% coverage work. Only en and zh-Hans are maintained; other editions are removed from the current branch and retained in history. Whitepaper v0.1.1 and public documentation use shared paired text; resuming multilingual work requires a new user scope change.

<a id="b17"></a>

区分三组概念：一次实验经费、长期补充资金与本地生产自给需要不同证据；AI 主动负责工作不等于独占权力；白皮书和角色草稿不等于组织已部署。

Distinguish three sets of concepts: funding one experiment, replenishing resources over time, and local production require different evidence; active AI responsibility is not exclusive power; whitepapers and role drafts are not deployed organizations.

<a id="b18"></a>

后续记录格式：ID、日期、来源类型、原结论、新结论与理由、状态、关联证据。被替代的结论保留并标明后继 ID；不得静默把建议升级为已批准决定。

Future record format: ID, date, source type, previous conclusion, new conclusion and reason, status, and evidence. Retain superseded conclusions with a successor ID; do not silently upgrade suggestions into approved decisions.
