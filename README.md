# 共生公域 · Symbiotic Commons

<a id="b01"></a>

**让智能的增长成为共同的自由。**

**Let growing intelligence become shared freedom.**

<a id="b02"></a>

如果技术进步能让我们更有时间休息、照顾彼此，并拒绝有损尊严的工作，我们应该怎样组织共同生活？

If technological progress could give us more time to rest, care for each other, and refuse degrading work, how should we organize shared living?

<a id="b03"></a>

共生公域是一份可公开修订的自愿人机共生共同体提案。AI 在可撤销授权下主动承担研究、规划和协调；人类贡献经验、判断、关系与现实行动。共享资源应当转化为尊严、生活保障和属于自己的时间。

Symbiotic Commons is an openly revisable proposal for voluntary human–AI communities. AI actively undertakes research, planning, and coordination under a revocable mandate; people contribute experience, judgment, relationships, and real-world action. Shared resources should become dignity, material security, and time people can call their own.

<a id="b04"></a>

**当前版本：白皮书 v0.1.1，提案阶段。** 名称暂定；尚未建立居住社区、募资渠道、自治资金池或持续 agent 服务。

**Current version: whitepaper v0.1.1, proposal stage.** The name is provisional; no residence, fundraising channel, autonomous treasury, or continuous agent service has been established.

Following the initiator’s latest request, only Simplified Chinese and English are maintained. The whitepaper and public documentation correspond fully paragraph by paragraph; summaries do not replace translations. This scope decision supersedes the former 78-edition and 90%-population-coverage plan; earlier drafts remain in Git history. No population-coverage claim accompanies the two current languages. Independent human review remains pending.

<a id="b07"></a>

我们提议：以数十年乃至更长的时间尺度探索制度，同时改善当下生活；由 AI 主动协调并接受成员授权；以明确规则约束共同资金；条件成熟时开展至少十名自愿成年人的有限期生活实验；公开记录成果、失败与分歧。

We propose exploring institutions over decades or longer while improving life today; active AI coordination under member mandates; shared funds constrained by explicit rules; finite living experiments for at least ten consenting adults when ready; and public records of results, failures, and disagreements.
